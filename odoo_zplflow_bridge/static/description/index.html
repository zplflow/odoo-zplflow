Step-by-Step Usage Guide

1

Global Settings (Optional Cloud Credentials)

Navigate to Settings → General Settings and select the ZplFlow Thermal Printing section from the left sidebar:

  • ZplFlow API URL: Defaults to https://api.zplflow.io.
  • ZplFlow API Key: Enter your API key from your www.zplflow.io account (only required for cloud pipelines and PDF-to-ZPL conversion; local printing works 100% offline).
  • ZplFlow Default Pipeline ID: Optional fallback template ID applied across all printers.
2

Register and Test a Thermal Printer

Go to Inventory → Configuration → Thermal Printers (ZplFlow) and create a new printer record:

Protocol When to choose Required parameters
Zebra Link-OS IPPS Modern firmware (V89.21.46Z+). Encrypted TLS on port 631. IP Address / Hostname, Port (631), Verify TLS (uncheck for self-signed).
Raw Socket TCP Virtually all network Zebra printers, Ethernet adapters & print servers. IP Address, Port (9100 or 9001).
Direct USB Printer plugged directly into the Odoo server via USB cable. Device Path (e.g. /dev/usb/lp0, /dev/usb/lp2).

Test it immediately: Click the Test Print button in the upper header. A diagnostic label with barcode and printer details will be printed on the spot!

3

Printing Shipping Labels from Transfers

Open any Delivery Order or Receipt under Inventory → Operations → Transfers:

  1. The transfer automatically inherits your default active printer (or choose a specific one in the form field).
  2. Click the primary button Print Thermal Label (ZplFlow) in the top action bar.
  3. The shipping label is instantly generated and emitted by the printer. A green success confirmation toast appears on screen.
4

Printing Product Barcode Labels (Direct Hardware Output)

Open any product record under Inventory → Products → Products and click Print Labels:

  1. In the Choose Labels Layout wizard, your ZplFlow printer is automatically selected and the format defaults to ZPL Labels.
  2. Enter the desired quantity and click Confirm.
  3. ZplFlow dispatches the stream straight to the printhead without downloading files or triggering browser save prompts.
  4. Tip: If a PDF format (Dymo, 2×7, 4×7) is selected with an active API key, ZplFlow automatically rasterizes and converts the PDF to ZPL in the cloud before printing.

Direct USB & Docker Deployment Notes

When using direct USB character devices (/dev/usb/lpX) on Linux or inside Docker containers:

# 1. Mount device inside your docker-compose.yml:
services:
  web:
    devices:
      - "/dev/usb/lp2:/dev/usb/lp2"

# 2. Grant write permissions on the host:
sudo chmod 666 /dev/usb/lp2

# 3. (Optional) Make permissions permanent across reboots with a udev rule:
echo 'KERNEL=="lp[0-9]*", MODE="0666"' | sudo tee /etc/udev/rules.d/99-zebra.rules
sudo udevadm control --reload-rules && sudo udevadm trigger

Native installations simply require adding the Odoo system user to the lp Linux group: sudo usermod -aG lp odoo.

Developer API & Automated Actions

You can trigger label printing from server actions, automated workflows, or custom modules with a single line of Python:

# Locate printer by name or default
printer = env['zplflow.printer'].search([('active', '=', True)], limit=1)

# Send raw ZPL string
printer.print_zpl_stream("^XA^PW812^LL1218^BY2,3,100^FO50,50^A0N,40,40^FDHello World^FS^XZ")
